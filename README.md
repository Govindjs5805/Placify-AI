### AI-Powered Placement Package Predictor

Placify AI is a machine learning-powered web application that predicts a student's expected placement package based on academic performance, technical skills, internships, projects, and certifications. The platform provides data-driven insights to help students assess their placement readiness and identify areas for improvement.

---

## 📌 Features

- Predicts expected placement package using Machine Learning.
- Analyzes multiple student performance metrics.
- Interactive and user-friendly Streamlit dashboard.
- Real-time salary package prediction.
- Data preprocessing and feature engineering pipeline.
- Visual insights into factors affecting placement outcomes.

## 📊 Input Parameters

The prediction model considers the following factors:

- CGPA
- Number of Projects
- Internship Count
- DSA Problems Solved
- Communication Skills Rating
- Certifications Count

---

## 🎯 Output

The model predicts:

- Expected Placement Package (LPA)

Example:

| Feature | Value |
|----------|----------|
| CGPA | 8.7 |
| Projects | 5 |
| Internships | 2 |
| DSA Solved | 350 |
| Communication | 8 |
| Certifications | 4 |

### Predicted Package:
**₹12.4 LPA**
